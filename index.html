Projeto Agrinho

O Projeto Agrinho é uma iniciativa promovida pelo Sistema FAEP/SENAR-PR (Federação da Agricultura do Estado do Paraná e Serviço Nacional de Aprendizagem Rural) voltada para a educação e o desenvolvimento social e ambiental nas áreas rurais do estado do Paraná. O objetivo principal é levar informações sobre cidadania, saúde, meio ambiente e qualidade de vida para alunos e comunidades rurais, por meio de atividades pedagógicas e concursos.

A estrutura do site é baseada em HTML, que define a semântica e o layout do conteúdo, enquanto o CSS é usado para estilizar a página visualmente, incluindo cores, tipografia e a disposição dos elementos.

O CSS personaliza o visual do site, usando variáveis para cores, estilizando o texto com uma fonte importada do Google Fonts e aplicando um esquema de cores suaves e botões interativos. O uso de HTML e CSS é importante pois assim é possível criar um site acessível e esteticamente agradável.

Projeto Senha

O Projeto Gerador de Senhas tem como finalidade orientar o desenvolvimento de uma aplicação voltada à criação e ao fortalecimento de credenciais digitais. A proposta se inicia com a elaboração do protótipo no Figma, definindo a estrutura visual e funcional da interface.

Em seguida, são produzidos os arquivos HTML e CSS que organizam o conteúdo, estabelecem o layout e reforçam conceitos fundamentais já estudados. O uso de JavaScript amplia o projeto ao permitir manipular o DOM, criar funções, aplicar laços de repetição e configurar eventos para ajustar o número de caracteres e gerar senhas aleatórias.

A etapa final aborda a classificação dessas senhas, aplicando métodos matemáticos baseados em entropia para estimar o nível de segurança e o tempo necessário para sua quebra por tentativas automatizadas.

Projeto IA

Este projeto foi desenvolvido com o propósito de estimular a análise crítica de questões sociais, culturais e ambientais por meio de uma estrutura narrativa interativa. A proposta permite que cada participante selecione a temática que deseja explorar; no caso apresentado, o foco recai sobre os impactos do uso da inteligência artificial no cotidiano atual.

O sistema dispõe de um texto inicial que apresenta duas alternativas de continuidade, cada uma conduzindo o usuário a diferentes caminhos narrativos. À medida que as escolhas são realizadas, novos trechos são exibidos, compondo uma progressão clara e organizada.

Ao final do processo, o projeto reúne as decisões feitas ao longo do percurso e produz uma síntese narrativa que evidencia as consequências e implicações resultantes, permitindo uma reflexão estruturada sobre o tema escolhido.

Projeto Colab

Este projeto tem como objetivo introduzir os estudantes ao campo da análise exploratória de dados, utilizando conceitos fundamentais da ciência de dados para compreender informações de maneira estruturada. A proposta inclui a formulação de perguntas que orientam toda a investigação realizada.

Utilizaremos o Google Colab como ambiente principal, permitindo registrar observações, construir códigos em Python e organizar resultados de forma integrada. Essa ferramenta possibilita combinar textos explicativos, células de execução e elementos visuais que enriquecem a interpretação.

A análise final reunirá tabelas, gráficos, descrições e trechos de código, destacando padrões relevantes encontrados no conjunto estudado. Por meio desses recursos, será possível identificar relações, comparar informações e produzir conclusões claras baseadas nos dados obtidos.
